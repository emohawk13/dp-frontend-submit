The Basics

If you look below, you will see a basic way of using the Docker CLI (command line interface). There are a few ways to manage Docker containers, but most use either the CLI or Docker Desktop. I prefer CLI, I feel that there is more control and it give a better instruction of understanding everything you are expecting of you container.

Lets install the most recent version of Ubuntu, looking below is a command you can run after following the instructions related to your OS here, another personal preference, I like to run things like this using Linux. After installation, you can run this command within the terminal.

sudo docker pull ubuntu |

You will see a bunch of lines of code running through downloading your Docker Image. After your terminal returns to normal you will see a set of random characters, this represents the docker container ID. To verify the image was successfully pulled and running copy the container ID and replace <container id> in the line of code below and run the command.

sudo docker ps <container id> |

This will show something along the lines of the output below:

CONTAINER ID IMAGE COMMAND CREATED STATUS PORTS NAMES
1a2b3c4d5e6f ubuntu "sleep 1000" 1 seconds ago Up 2 seconds pedantic_brown

Congratulations!!!

You successfully set up your first image and ran it to turn it into a working container!!
